# todolist
todolist in c 

## Fonctionnality 

- Ajouter une tâche : Saisir un texte descriptif pour une nouvelle tâche.

- Afficher les tâches : Lister toutes les tâches enregistrées avec leur numéro et leur état (à faire / fait).

- Marquer comme complétée : Changer l'état d'une tâche via son numéro.

- Supprimer une tâche : Retirer une tâche de la liste.

- Sauvegarde automatique : Enregistrer la liste dans un fichier texte (tasks.txt) à la fermeture et la recharger au démarrage.
